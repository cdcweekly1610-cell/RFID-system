混凝土試體 RFID 核心追蹤管理

專為工程品管與實驗室設計的輕量化純前端網頁應用程式。透過 RFID 晶片追蹤混凝土試體的取樣與試壓排程，並以 Google Gemini AI 辨識現場「混凝土取樣記錄表」照片自動建檔，資料可同步至 Notion 永久保存。

不需要安裝任何軟體或伺服器，用瀏覽器開啟 index.html 即可使用。

✨ 功能特色
1. 📊 數據儀表板
庫存與狀態總覽：即時顯示標籤總數、已綁定表單、已試驗、尚未試驗的試體數量。
試壓提醒：自動比對今天日期，預告下一次會驗項目與倒數天數，當日或即將到期的項目會醒目標示。
2. 🏷️ RFID 晶片核心檢視
依表單分組：同一張取樣表單的試體晶片集中顯示在同一張卡片。
差異標示：同批晶片碼的相同部分以一般字體顯示，不同之處以橘色標出，方便核對。
拖曳指定 7 天試體：將試體小卡拖曳到卡片下方的虛線框，即可指定 7 天試壓的試體；點擊綠色標籤可取消。
一鍵複製：卡片右上角的複製按鈕會複製取樣日期與各試體 RFID 末 12 碼，格式如下：
  8/13
  序號 1：15D8ECB20B25
  序號 2：15E8ECB20B25
快速跳轉：點擊晶片小卡，會跳到總表並篩選出該張表單。
3. 📋 完整表單與試體清單
以表格列出所有表單與試體，可搜尋篩選。
直接編輯：在表格內修改表單內容，試壓日會自動重新計算。
刪除：點擊列表最右側的垃圾桶圖示，即可刪除整張表單。
4. 🤖 AI 拍照辨識新增（Google Gemini）
在「新增試體記錄與綁定」頁籤上傳或拍攝取樣記錄表照片，AI 會自動填入表單編號、取樣日期（民國年自動轉西元）、工程名稱、供應廠商、取樣位置、設計強度，以及最多 4 顆 RFID 晶片碼。
照片中沒有的試體會自動取消勾選；RFID 長度不是 24 碼時以紅字提醒，請人工核對後再儲存。
也可以完全手動填寫。
試壓日自動試算：依取樣日期推算第 7 天與第 28 天的試壓日，遇到週六、週日自動順延至週一（國定假日不會自動判斷，請自行調整）。
5. 📅 實驗室試壓日排程
今日任務：列出今天需要試壓的表單與試體編號。
14 日排程：以表格列出未來兩週的試壓行程，方便實驗室預先安排。
6. 🔗 Notion 自動同步
新增或修改表單時，會在背景自動寫入 Notion 資料庫（每張表單一筆），右下角會顯示同步結果。
在系統設定中可「測試連線」，或用「全部同步到 Notion」一次補傳所有表單；已存在的表單會更新，不會重複新增。
透過 Google Apps Script（notion-sync.gs）轉送，Notion 金鑰只存在 Google 端，不會出現在網頁上。
7. 其他
匯出報表：右上角「匯出報表」可下載 CSV 檔。
示範資料：第一次開啟時會自動載入 7 筆示範表單，可隨時點右上角「重新載入示範記錄表」重置。

🚀 設定步驟

所有金鑰都在網頁上設定，不需要、也不要修改程式碼。

一、AI 照片辨識
到 Google AI Studio 建立 API Key（AIza 或 AQ. 開頭）。
開啟網站，點右上角齒輪「系統設定」，貼到「Google Gemini API Key」欄位後儲存。
「Gemini 模型名稱」留空即可。日後模型停用時，在這裡改成新名稱。
二、Notion 同步

1. 建立 Notion 整合

到 Notion 整合頁面 新增「內部」整合，複製「內部整合密鑰」（ntn_ 開頭）。

2. 準備 Notion 資料庫

建立一個整頁資料庫，欄位不需要自己建立。
在資料庫右上角點「⋯ → 連線」，加入剛剛建立的整合。
複製資料庫連結。

3. 建立 Google Apps Script

到 Google Apps Script 新增專案，貼上 notion-sync.gs 的全部內容並存檔。
在「專案設定 → 指令碼屬性」新增：
屬性	值
NOTION_TOKEN	Notion 整合密鑰
NOTION_DATABASE_ID	Notion 資料庫連結
SYNC_SECRET	自訂一組同步密碼
函式選擇 testSetup 並按「執行」，看到「✅ 已連上 Notion 資料庫」即成功，資料庫欄位也會自動建立。
「部署 → 新增部署作業 → 網頁應用程式」：
執行身分：我
誰可以存取：所有人
部署完成後複製網址（.../exec）。

4. 回到網站設定

在齒輪設定中填入「Notion 同步網址」與「Notion 同步密碼」，按「測試連線」。

修改 notion-sync.gs 後，需要到「部署 → 管理部署作業 → 編輯 → 版本：新版本」重新部署，修改才會生效，網址不會改變。

🔒 安全注意事項
這是公開專案，任何人都能看到所有檔案與修改紀錄。絕對不要把金鑰、密碼寫進任何檔案。
金鑰存放位置：
Gemini API Key、Notion 同步網址與密碼 → 網頁齒輪設定（只存在各自的瀏覽器）。
Notion 金鑰、資料庫 ID、同步密碼 → Apps Script 的「指令碼屬性」。
設定只存在當前瀏覽器。換電腦、換瀏覽器或清除瀏覽資料後，需要重新填寫。
建議在 Google AI Studio 為 API Key 設定用量上限。
.gitignore 只對 Git 指令與 GitHub Desktop 有效。用 GitHub 網頁「Upload files」上傳時不會套用，請只上傳上表列出的檔案。建議在 repo 的 Settings 開啟 Secret Protection 與 Push protection。
⚠️ 注意事項
資料保存：表單資料存在瀏覽器 localStorage，清除瀏覽器資料就會遺失。請設定 Notion 同步作為永久備份。
同步方向：目前只會由網站寫入 Notion；在 Notion 中修改的內容不會回傳到網站。
開啟方式：請用 Chrome、Edge 或 Safari 直接開啟網頁。某些 App 的內嵌預覽視窗會阻擋對外連線，導致 AI 辨識與 Notion 同步失敗。
下載檔名：重複下載時，瀏覽器可能把檔名改成 index (1).html。上傳到 GitHub 前請先改回 index.html，否則網站不會更新。
